# Islamic Etude Market (متجر إتيد الإسلامي)

مستودع الحزم والبطاقات والسمات الإسلامية المخصصة لتطبيق Etude، تشمل:
- **متشابهات القرآن الكريم** بالرسم العثماني المصحفي وقواعد الضبط.
- **الأحاديث النبوية الشريفة والمتون العلمية** (كالأربعين النووية والآجرومية).
- **السمات الإسلامية المريحة للعين** (كمصحف المدينة).

## محتويات المستودع
- `entries/types/`: أنماط البطاقات المخصصة (مثل `quran-mutashabihat`).
- `entries/decks/`: المجموعات والحزم الجاهزة للحفظ والمراجعة بالتكرار المتباعد.
- `entries/themes/`: السمات اللونية الإسلامية.
- `index.json`: فهرس المتجر العام الذي يقرأه التطبيق.

## الاستخدام والتثبيت
من داخل التطبيق، افتح تبويب **المتجر (Market)** لتصفح الحزم وتثبيتها بضغطة زر واحدة، أو عبر سطر الأوامر (CLI):
```sh
etude market list
etude market install quran-mutashabihat-baqarah
etude market install nawawi-forty
etude market install islamic-mushaf
```
