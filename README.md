# متجر وِكَاء — Wikae Market

> **«المذاكرةُ وِكاءُ الحِفْظ»**  
> **مستودع الحزم والبطاقات والسمات الإسلامية لمنصة وِكَاء**

مستودع الحزم والبطاقات والسمات الإسلامية المخصصة لمنصة **وِكَاء (Wikae)**، تشمل:
- **متشابهات القرآن الكريم**: بطاقات تفاعلية بالرسم العثماني المصحفي تضبط الآيات المتشابهة وتوضح اللفظ المفصلي وقواعد التقعيد والربط (سورة البقرة كاملة ومحققة).
- **الأحاديث النبوية الشريفة والمتون العلمية**: متون محققة ومضبوطة بالشكل التام (الأربعون النووية كاملة، متن تحفة الأطفال في التجويد، والمقدمة الجزرية لابن الجزري).
- **السمات الإسلامية المريحة للعين**: سمات ألوان هادئة مستوحاة من مصحف المدينة المنورة (المظهر النهاري `islamic-mushaf` والمظهر الليلي الكحلي المذهب `islamic-dark`) لتناسب جلسات المذاكرة الطويلة ومراجعات الأسحار.

## محتويات المستودع
- `entries/types/`: أنماط البطاقات المخصصة (مثل نمط `quran-mutashabihat`).
- `entries/decks/`: المجموعات والحزم الجاهزة للحفظ والمراجعة بالتكرار المتباعد.
  - `quran-mutashabihat-baqarah.json`: متشابهات سورة البقرة (19 موضعاً متشابهاً داخلياً ومع السور الأخرى).
  - `nawawi-forty.json`: متن الأربعين النووية كاملاً (42 حديثاً) مع التخريج والفوائد.
  - `matn-tuhfat-al-atfal.json`: متن تحفة الأطفال للجمزوري (61 بيتاً كاملاً مع بطاقات التسميع والترتيب وملء الفراغات).
  - `matn-al-jazariyyah.json`: المقدمة الجزرية في التجويد (كاملة ومقسمة وفق الأبواب).
- `entries/themes/`: السمات اللونية الإسلامية (`islamic-mushaf` و `islamic-dark`).
- `index.json`: فهرس المتجر العام الذي تقرأه المنصة وتطبيق سطح المكتب والهاتف.

## الاستخدام والتثبيت
من داخل تطبيق **وِكَاء (Wikae)**، افتح تبويب **المتجر (Market)** لتصفح الحزم وتثبيتها بضغطة زر واحدة، أو عبر سطر الأوامر (`wikae`):
```sh
wikae market list
wikae market install quran-mutashabihat-baqarah
wikae market install nawawi-forty
wikae market install matn-tuhfat-al-atfal
wikae market install matn-al-jazariyyah
wikae market install islamic-mushaf
wikae market install islamic-dark
```
